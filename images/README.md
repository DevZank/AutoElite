## Image Specifications

- Format: JPG
- Resolution: 1920x1080 pixels (hero image), 800x600 pixels (others)
- Quality: High quality, professional automotive images
- Optimization: Compressed for web use (under 200KB each)

## Alt Text Guidelines

All images include descriptive alt text that:
- Accurately describes the content and function of the image
- Is concise but informative
- Includes relevant keywords for SEO
- Provides context for visually impaired users

## Visual Design Recommendations

For maximum visual impact with the new premium design, images should:

1. **Hero Image**: 
   - Professional automotive workshop with modern equipment
   - Mechanics working on luxury vehicles
   - Dynamic lighting to showcase the premium environment

2. **Service Images**:
   - High-quality photos of actual services being performed
   - Professional equipment and tools visible
   - Clean, organized workshop environment
   - Mechanics in branded uniforms

3. **Gallery Images**:
   - Before/after shots when possible
   - Detailed views of work in progress
   - Team collaboration moments
   - Customer satisfaction moments

4. **Color Consistency**:
   - Images should complement the blue (#0d2b4e), red (#e63946), and gold (#ffd166) color scheme
   - Avoid images with dominant colors that clash with the brand palette
   - Maintain consistent brightness and contrast levels

5. **Composition**:
   - Professional photography with good lighting
   - Clear focus on the subject
   - Adequate space for potential overlay text
   - High-resolution images that look sharp on all devices
