# AutoElite - Website Profissional Automotivo Premium

## Descrição do Projeto

Este é um website profissional premium para uma empresa do setor automotivo, desenvolvido com HTML, CSS e JavaScript. O site apresenta um design moderno e sofisticado com uma identidade visual forte, totalmente responsivo e inclui todas as práticas recomendadas de acessibilidade, incluindo textos alternativos descritivos para todas as imagens.

## Estrutura do Website

1. **index.html** - Página principal do website
2. **styles.css** - Arquivo de estilos com design moderno e responsivo
3. **script.js** - Funcionalidades interativas em JavaScript
4. **images/** - Diretório para imagens do site
5. **placeholder.html** - Versão com placeholders para visualização

## Seções do Website

1. **Header** - Cabeçalho com logo e navegação
2. **Hero** - Seção principal com chamada para ação
3. **Serviços** - Grade com os principais serviços oferecidos
4. **Sobre** - Informações da empresa e valores
5. **Galeria** - Portfólio de trabalhos realizados
6. **Contato** - Formulário de contato e informações
7. **Footer** - Rodapé com links e informações adicionais

## Recursos e Funcionalidades

- Design premium com identidade visual forte
- Paleta de cores sofisticada (azul marinho, vermelho premium, dourado)
- Tipografia moderna com Google Fonts (Roboto e Oswald)
- Efeitos de gradiente e sombras para profundidade visual
- Animações e transições suaves
- Design totalmente responsivo (móvel, tablet e desktop)
- Navegação suave entre seções
- Formulário de contato funcional
- Práticas de SEO e acessibilidade
- Textos alternativos descritivos para todas as imagens
- Ícones vetoriais com Font Awesome

## Como Usar

1. Substitua as imagens no diretório [images/] com as imagens reais do seu negócio
2. Atualize as informações de contato na seção "Contato"
3. Personalize o conteúdo de acordo com os serviços oferecidos
4. Configure o formulário de contato para enviar mensagens (requer backend)
